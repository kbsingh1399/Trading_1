## 2. Master Two-Tier TDMA Architecture (Zero Overlap Guarantee)

To guarantee that **none of the scrapers ever overlap**, the pipeline transitions from ad-hoc sleep intervals to a deterministic **Time-Division Multiple Access (TDMA)** framework:

```
Hour Cycle: [00:00 ---------------------------------------------------------------- 59:59]
Macro Windows:
  :00:00 - :01:15  --> DAEMON 2: Whales Sweep (45s exclusive)
  :10:00 - :12:30  --> DAEMON 3: Liquidation Sweep (120s exclusive)
  :15:00 - :16:15  --> DAEMON 2: Whales Sweep (45s exclusive)
  :25:00 - :27:30  --> DAEMON 3: Liquidation Sweep (120s exclusive)
  :35:00 - :36:15  --> DAEMON 2: Whales Sweep (45s exclusive)
  :50:00 - :51:15  --> DAEMON 2: Whales Sweep (45s exclusive)
  :55:00 - :57:30  --> DAEMON 3: Liquidation Sweep (120s exclusive)

Unreserved Minutes (79.2% of the hour):
  Every Minute :00s - :25s  --> DAEMON 4: TV Liquidation Map (sub-second API, ~16s)
  :25s - :30s               --> 5s CDP Socket Cooldown & Tab GC
  Even Minutes :30s - :55s  --> DAEMON 1: Footprint Terminal (~20s)
  :55s - :60s               --> 5s Pre-Boundary Buffer
```

### Mathematical Guarantee of Non-Overlap:
1. **Tier 1 (Macro Minutes)**: When minute $\in [0, 15, 35, 50]$ or $\in [10, 11, 12, 25, 26, 27, 55, 56, 57]$, Daemons 1 and 4 sleep immediately.
2. **Tier 2 (Micro Second Phase)**: In all open minutes, Daemon 4 is locked to second interval `[00, 25]`, and Daemon 1 is locked to second interval `[30, 55]`.
3. **Collision Probability**: **0.00%**. At no point in time do two browser tabs operate simultaneously.

## 3. Cloudflare WARP True IP Rotator on Windows

### 3.1 Two-Phase IP Rotation Engine
`warp-cli tunnel rotate-keys` is replaced by a two-stage rotation strategy in `Terminal/collector_lock.py`:

1. **Stage 1 (Fast Toggle to Direct ISP IP, ~2s)**:
   - Command: `warp-cli disconnect`
   - Switches system egress from Cloudflare WARP (`104.28.200.x`) to Direct ISP IP (`49.38.14.x`).
   - Immediately provides a completely fresh IP and different Autonomous System Number (ASN).
2. **Stage 2 (Full Cloudflare Provisioning, ~5s)**:
   - When returning to WARP or when ISP IP is throttled:
     ```cmd
     warp-cli disconnect
     warp-cli registration delete
     warp-cli registration new
     warp-cli connect
     ```
   - Re-registers with Cloudflare edge and provisions a brand new WARP egress address.

### 3.2 Network Stabilization Handshake & Guardrails
- **DNS / Routing Settling Loop**: Probes `https://api.ipify.org` with a 10.0-second deadline. Ensures Chrome never encounters `ERR_NETWORK_CHANGED` or socket disconnects.
- **MatchTrader Live Execution Invariant**:
  - `rotate_warp_ip()` inspects `Database/.locks/order_execution_inflight.lock`.
  - If a live order is currently in-flight on MatchTrader, **rotation is strictly rejected** to preserve the trading WebSocket.
  - The lock automatically expires after **20.0 seconds** (TTL guardrail) to prevent deadlocks.
- **Reverse Sentinel Shield**: Daemon 5 (`5_wake_on_footprint_signal.py`) inspects `warp_execution.lock` before sending order clicks, pausing up to 6.0s if an IP rotation is actively renegotiating.

## 4. CoinGlass In-Page Error Recovery Handshake (Daemon 3)

In `3_coinglass_liquidation_levels.py`, implement automated recovery when CoinGlass displays the error overlay:

```javascript
// Block Detection JS Expression
(() => {
    const text = document.body.innerText || "";
    const hasError = text.includes("Failed to load liquidation levels");
    const retryBtn = document.querySelector(".ll-overlay button, .ll-stage.error button");
    const hasCloudflare = document.title.includes("Just a moment...") || !!document.querySelector("#challenge-running");
    return {
        is_blocked: hasError || hasCloudflare,
        has_retry: !!retryBtn,
        reason: hasCloudflare ? "CLOUDFLARE_CHALLENGE" : (hasError ? "FAILED_TO_LOAD" : "OK")
    };
})()
```

### Recovery Protocol:
1. If `has_retry`: Scraper clicks `.ll-overlay button`, waits 2.5s.
2. If data loads (`Last price != null`): Resumes sweep without IP rotation.
3. If error persists or Cloudflare challenge appears:
   - Calls `rotate_warp_ip(context="LiquidationScraper", reason="FAILED_TO_LOAD")`.
   - Reloads tab via CDP `Page.reload`.
   - Re-extracts data. Maximum 2 retry attempts per symbol.

## 5. Signal Parquet Schema Remediation & Migration Plan

### 5.1 Remediation for `realtime_trade_alerts.parquet`
1. **Schema Standardization**:
   - Primary Columns: `evaluated_at_utc`, `evaluated_at_ist`, `symbol`, `mt5_symbol`, `direction`, `is_actionable`, `confluence_score`, `sig_name`, `sig_code`, `candle_utc`, `candle_ist`, `entry_price`, `stop_loss`, `take_profit_1`, `rr_ratio`, `sl_pct`, `whale_imbalance`, `cvd_slope`, `regime`, `timesfm_cvd_dir`, `timesfm_cvd_conf`, `timesfm_price_dir`, `timesfm_price_conf`, `tv_liq_bias`, `tv_liq_exhaustion`, `reasons`.
2. **Migration & Cleanup**:
   - Consolidate legacy `timesfm_direction` into `timesfm_price_dir` and drop `timesfm_direction`, `timesfm_confidence`, `timesfm_drift`.
   - Backfill missing `evaluated_at_ist` and `candle_ist` from UTC timestamps.
   - Replace empty `mt5_symbol` strings with normalized fallback `${symbol}USD.p`.
   - Remediate `'ERROR'` in `regime` with historical ATR volatility fallback.

### 5.2 Remediation for `coinglass_aggregated_futures_signals.parquet`
1. **Schema Partitioning & Column Standardization**:
   - The 12,922 raw CoinGlass signals rightfully lack local synthetic bar metrics (`volume`, `delta`, `poc_price`) because they represent external exchange events.
   - Standardize nullable columns: fill missing `source` with `'coinglass_native'`, `asset_class` with `'Crypto'`.
   - Backfill missing IST timestamps (`candle_ist`, `time_ist`, `datetime_ist`, `time_ist_ms`) from `time_ms` across all historical rows.
2. **Single-Writer Governance**:
   - `1_coinglass_footprint_scraper.py` is the designated authority for `coinglass_aggregated_futures_signals.parquet`.
   - Local synthetic signals from `unified_api_footprint_engine.py` are isolated or labeled explicitly with `source='binance_api_synthetic'`.

### 5.3 Remediation for `footprint_signals.parquet`
- `Database/Signals/footprint_signals.parquet` is recognized as an unmaintained legacy artifact from the deprecated `crypto_footprint_sentinel.py`.
- **Action**: Archive or reconstruct `footprint_signals.parquet` from `coinglass_aggregated_futures_signals.parquet` with complete IST enrichment, ensuring no downstream systems depend on the stale file.
